# 単体インストーラー検証記録

2026-11-11、0.5.1-preview.1 / 0.5.2-preview.1（DLL 0.3.1）。

## 確認済み

- .NET 10 Release self-contained publish成功、Inno Setup 7.1.1で単一EXEの生成成功。サイズ約52MiB。
- 本体、32/64 Windhawkエンジン、x64 helper、タスクバーDLL、C++ランタイム、シンボルキャッシュを新規ステージングへ同梱。既存ユーザー用のWindhawk AppDataやプロファイルを複製していない。
- WindhawkのUI・コンパイラー・DIA/SymSrv DLLを含めず、同梱構成の本体をComputer Useで起動。保存済みJellyfin接続の復元、本体からエンジンの自動起動、IPC通信、タスクバー「配置済み」を確認。
- 二度起動してもメインウィンドウは1つで、既存ウィンドウに復帰した。
- 本体の「完全終了」でウィンドウが消え、同梱エンジンの実行中Modメタデータが消えることを確認。追加のExplorerクラッシュダンプは発生しなかった。
- 最終コードの再生状態自己テスト、480枚の仮想スクロール・戻る操作等の画面回帰テストはexit code 0。
- 公開する本体ソースにテストサーバーURLやユーザー情報を埋め込んでいない。ステージングにconnection.bin、userprofile.json、クラッシュダンプを含めない。
- GPL本文、MIT通知、LLVM/MinGW/.NET/Inno Setupの表示、Windhawk 1.7.3対応ソースZIP、本体・DLL・インストーラーのソースを同梱する。
